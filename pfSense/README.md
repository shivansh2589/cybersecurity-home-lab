# pfSense Firewall Project

## Objective

Set up and configure pfSense as the main firewall for my cybersecurity home lab.

## Lab Purpose

This project is designed to practice:

- Firewall installation
- WAN and LAN configuration
- Network interface assignment
- DHCP
- NAT
- Firewall rules
- Network troubleshooting
- Secure home lab design

## Current Setup

Internet → pfSense Firewall → Switch → Lab Devices / Wireless Access Point

## Hardware

- Dedicated laptop running pfSense
- USB Ethernet adapters
- Network switch
- Wireless access point / mesh system
- Windows and Linux lab computers

## Skills Practiced

- TCP/IP
- Network Security
- Firewall Administration
- Routing
- NAT
- DHCP
- Troubleshooting
- Access Control
